# @elysia9x/plugin-claude

Adds Claude Code project rules and a reusable Elysia9X audit skill.

```bash
bunx @elysia9x/plugin-claude install
```

The installer creates:

- `.claude/rules/elysia9x.md`
- `.claude/skills/elysia9x-audit/SKILL.md`

Existing files are preserved. Pass `--force` to replace files managed by this plugin.
