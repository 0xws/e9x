# @elysia9x/cli

Bun-native CLI for initializing and auditing projects that follow the Elysia9X engineering standard.

```bash
bunx --package @elysia9x/cli elysia9x init
bunx --package @elysia9x/cli elysia9x doctor
bunx --package @elysia9x/cli elysia9x scan
bunx --package @elysia9x/cli elysia9x permissions audit

elysia9x integrations list
elysia9x integrations install claude
elysia9x integrations install codex
elysia9x integrations install cursor
elysia9x integrations install vibe
elysia9x integrations install vibe --user
```

Static analysis is evidence, not proof. Dynamic routes and runtime authorization require runtime manifests and integration tests. See the [main README](../../README.md) and [documentation](https://0xws.github.io/e9x/).
